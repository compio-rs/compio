# Code of Conduct

We adhere to [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct). tl;dr: **be nice**.

## AI and LLM Usage

This section applies to generative AI and large language model tools. It is
adapted from the [Rust Project LLM Usage Policy][rust-llm-policy]. AI tools can
help people learn, analyze, and review. They do not replace contributor or
reviewer judgment. Contributors remain responsible for everything they submit.

This list is not exhaustive. If you are not sure whether a use is acceptable,
ask the maintainers before you share the output.

### Allowed

- Private use where only you see the output. This includes questions, summaries,
  private reviews, and possible solutions.
- Learning from generated ideas and then creating the contribution from scratch
  in your own words and style.
- Clearly marked experimental work that is not ready for normal review. You must
  disclose AI use before the work enters normal review.

### Not Allowed

- Posting AI-created issue comments, issue bodies, pull request comments,
  reviews, descriptions, documentation, diagnostics, or non-trivial source
  comments from a personal account.
- Treating an AI review as sufficient to merge, reject, or block a change.
- Using an AI review as a substitute for self-review or human review.
- Requiring contributors to use an AI tool.

### Allowed With Disclosure

The following uses require a clear disclosure that states how an AI tool was
used:

- Trivial changes where reasonable alternatives are nearly identical, such as
  typo fixes, link changes, or required type signatures.
- Machine translation.
- Finding a possible bug, if the contributor personally verifies the bug.
- Quoted AI output that is clearly marked as AI-created. Your own contribution
  must stand on its own without the quoted output.
- Review bots that a maintainer approved in advance. A review bot must use a
  separate account that identifies it as an AI tool and that users can block.
  Its comments are advisory and cannot block a change until a human reviewer
  verifies and endorses them.
- AI-created code when a maintainer agrees before the pull request is opened.
  The change must be non-critical, high quality, fully tested, and fully
  understood by both the author and the reviewer. The same maintainer who
  agreed to the work must review it.

Put the disclosure in the pull request or issue description. AI use does not
reduce the quality, testing, or review requirements for a contribution.

### Moderation

Be honest about AI use. Deliberately hiding or misrepresenting required
disclosure is a Code of Conduct violation and can result in moderation action.

[rust-llm-policy]: https://forge.rust-lang.org/policies/llm-usage.html#rules
